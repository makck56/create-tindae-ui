# Menu Visualizer 优化建议清单

本项目记录了 `menu-visualizer` 插件后续的可选优化方向，旨在提升开发体验和工具的健壮性。

## 1. 交互体验优化 (优先级：高)

- [ ] **左侧路由列表搜索/过滤**
    - 在路由列表顶部增加搜索框。
    - 支持按路由 Key (如 `ALARM_LIST`) 或中文注释 (如 `告警列表`) 进行模糊匹配。
- [ ] **菜单树拖拽排序 (Drag & Drop)**
    - 引入 `SortableJS` 实现可视化拖拽。
    - 支持跨层级移动（如将二级菜单提升为一级）。

## 2. 功能完整性 (优先级：中)

- [ ] **增强型图标选择器**
    - 提供 Ant Design Icons 的完整列表或常用图标快速选择。
    - 增加外部图标库链接。
- [ ] **扩展菜单属性支持**
    - 支持配置 `externalLink` (外部链接)。
    - 支持配置 `roles` / `permissions` (权限标识)。
    - 支持 `hideInMenu` 等 UI 控制开关。

## 3. 工程与稳定性 (优先级：中)

- [ ] **HMR 数据同步**
    - 监听 `menu.config.ts` 文件变动。
    - 通过 Vite WebSocket 通知 UI 自动刷新，实现编辑器与源码的双向同步。
- [ ] **死链检测与校验**
    - 自动标记 `menu.config.ts` 中引用的但在 `ROUTE_NAMES` 中已失效的路由。
    - 保存前进行重复项校验。

## 4. 极致体验 (优先级：低)

- [ ] **代码 Diff 预览**
    - 保存前展示代码变更对比，确保修改符合预期。
- [ ] **多语言支持**
    - 针对包含 i18n 逻辑的项目，支持在 Label 处配置国际化 Key。
