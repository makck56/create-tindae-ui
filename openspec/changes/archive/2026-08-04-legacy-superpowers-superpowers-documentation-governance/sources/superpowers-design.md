# Superpowers 历史文档

本目录保存早期通过 Superpowers 产出的头脑风暴、方案设计和实施计划。

## 当前定位

这些文件是历史过程记录，不再作为编码和验收的真相源。后续正式需求、设计、验收标准和任务拆分统一维护在 `openspec/`。

## 使用规则

- 可以阅读本目录了解早期背景、约束来源和方案演进。
- 不得把本目录中的旧计划直接当作当前实现依据。
- 如果旧文档中的内容仍然需要落地，应先迁移到 OpenSpec change。
- 新功能、新重构、新升级不得继续在 `docs/superpowers/specs/` 中新增正式规格。

## 推荐入口

- 文档治理规则：`docs/DOCUMENTATION_GUIDE.md`
- 当前正式规格：`openspec/specs/`
- 当前变更：`openspec/changes/`
- 已归档变更：`openspec/changes/archive/`
